# Mouse Movement Art Generator

An interactive web-based generative art project that turns mouse movements into visual artwork.

## 🎨 About

The **Mouse Movement Art Generator** is a creative coding project designed to transform the movement of a user's mouse into dynamic digital artwork.

Instead of simply interacting with a traditional webpage, users can move their cursor around the screen and create visual patterns and compositions through their movements.

The project includes multiple HTML versions, documenting the development and evolution of the Mouse Movement Art Generator over time.

## ✨ Features

- 🖱️ Interactive mouse movement tracking
- 🎨 Generates artwork based on cursor movement
- 🌐 Runs directly in a web browser
- ⚡ No installation or external software required
- 💻 Built as a lightweight web project
- 🔄 Multiple versions included to demonstrate project development
- 🧑‍🎨 Encourages experimentation and creative interaction
